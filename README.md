# MOONLIGHT 🌙

A simple webpage with a **parallax scrolling effect** and an inbuilt **dark/light mode toggle**.

## Features ✨
- **Parallax Scrolling:** Smooth background movement for a visually appealing experience.
- **Dark & Light Mode:** Toggle between themes using a sun/moon icon.
- **Responsive Design:** Works across different screen sizes.

## How to Use 🛠️
1. Open `index.html` in a browser.
2. Scroll to see the parallax effect.
3. Click the **sun/moon icon** to switch themes.

## Future Enhancements 🚀
- Improve responsiveness for smaller devices.
- Add more animations for a dynamic effect.
- Optimize performance for better scrolling experience.
